# Epigenetic Clamping Under Bioelectric Pattern Switching

## The Crucial Question

Does the bioelectric pattern dictate epigenetic state, or do epigenetic marks dictate anatomy regardless of bioelectric context? In a conflict between "wrong" marks and "wrong" bioelectric signals, who wins?

-   **Levin Prediction:** The bioelectric pattern is the setpoint. It will overwrite imposed epigenetic marks to re-establish the anatomy it specifies (Arm B reverts to bioelectric target).
-   **Sinclair/de Magalhães Prediction:** The epigenetic code is the controller. Imposed marks will override the bioelectric pattern (Arm B retains imposed anatomy), or the bioelectric reset alone (Arm C) will fail to revert the anatomy because the stable epigenetic state persists.

## Protocol

**Model:** Planaria (highly regenerative flatworms), capable of stable one-headed or two-headed morphologies.

**Arms:**
1.  **Arm A (Clamping):** Induce two-headed bioelectric state + epigenetic inhibitors (HDACi/DNMTi). *Test of dependency.*
2.  **Arm B (Conflict - The Decider):** In stable two-headed worms, use dCas9 epigenetic editing to impose *one-headed marks* at the posterior, while maintaining the *two-headed bioelectric gradient*.
3.  **Arm C (Reset):** In stable two-headed worms, reset bioelectric gradient to wild-type *without* touching epigenetic marks.

## Interpretation

-   **Levin Wins if:** Arm B reverts to two-headed anatomy (pattern overwrites marks); Arm C reverts to one-headed (pattern resets marks).
-   **Sinclair Wins if:** Arm B becomes one-headed (marks override pattern); Arm C stays two-headed (stable marks ignore bioelectric reset).
